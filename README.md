# Expert Knowledge Wiki

一次資料に残された熟練者の知見を、後継者とLLMが再利用できるWikiへ整理するためのプロンプト集です。

## プロンプト

[LLM Wiki試作プロンプト：M365 Copilot / Cline Desktop](llm_wiki_trial_prompts.md)

| 環境 | 使い方 | 出力 |
| --- | --- | --- |
| M365 Copilot | 同じ案件の資料を添付・選択し、該当プロンプトを貼り付ける | 目次と最大3ページのWiki原稿 |
| Cline Desktop | 入力・出力・制限付き作業フォルダを指定し、該当プロンプトを貼り付ける | Markdown、出典情報、処置済み画像、可能ならHTMLプレビュー |

## 基本方針

- **WHY → HOW → WHAT**の順で、目的・制約・判断理由を優先して残します。
- 記述を「資料に明記」「LLMによる推定」「不明」に分け、根拠のない理由を創作しません。
- 画像は可能なら切り出し、出典・説明・加工内容を付けます。
- 顧客・契約・機密情報を除外・一般化・仮名化します。画像、ファイル名、URL、付随ファイルも対象にします。
- 本人へのQ&Aは任意の補助とし、回答を待たずに作成を進めます。

## 試作の範囲

SharePoint Onlineへの掲載用原稿を作成します。自動アップロードや公開は含みません。まず少数の資料で、WHYの抽出、出典の正確性、画像処理を確認してください。

原資料を処理することが許可されたLLM接続先で実行してください。出力時の匿名化は、LLMへの入力送信を防ぐものではありません。未承認の環境では、事前に匿名化した資料を使用してください。

このリポジトリにはプロンプトと利用案内のみを保存し、業務の一次資料や機密を含む生成物は追加しないでください。プロンプトによる自動点検は、機密情報の完全除去を保証しません。
